# 우리 조 만들기

- 학생 화면: `https://<아이디>.github.io/<저장소>/#student`
- 교사 화면: `https://<아이디>.github.io/<저장소>/#teacher`

## 준비 (한 번만)
1. 구글 시트를 새로 만들고 **확장 프로그램 → Apps Script**에 `Code.gs` 내용을 붙여넣어 저장
2. **배포 → 새 배포 → 웹 앱**, 실행 사용자 "나", 액세스 권한 "모든 사용자" → 권한 승인
3. 나온 `.../exec` 주소를 `index.html` 맨 위 `API_URL = ""` 따옴표 안에 붙여넣기
4. `index.html`을 GitHub 저장소에 올리고 **Settings → Pages**에서 main 브랜치로 게시

## 수업 때
교사 화면을 띄우면 QR이 나오고, 학생 제출이 5초마다 모입니다. 다 모이면 "조 짜기".
다음 반으로 넘어갈 때는 "명단 모두 지우기".
